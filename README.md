# loretry-mcp

Official Loretry MCP client.
Follow the [agent setup guide](https://loretry.dev/install/agent.md).

Configure the stdio server as `npx --yes loretry-mcp@latest`. This server shares the local loretry-cli login.

Build from source: `npm ci && npm run build` (Node.js 20.19 or newer).

## See an example

Watch the [sine-wave explainer](https://loretry.dev/skills/loretry-cold-start). The sample shows how the height of a point moving around a circle traces one period of a sine wave.
